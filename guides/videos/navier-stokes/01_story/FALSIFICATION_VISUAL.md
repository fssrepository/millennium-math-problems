## Four visual states

### A — Expected decay

Show two separated spectral bands inside the established fluid world. A faint
teal or green dashed envelope falls toward the distant band. Keep the actual
fluid moving slowly.

Editor copy: `EXPECTED • DISTANT SCALES DECOUPLE`

### B — Adversarial result

Keep the same composition. The measured coral response remains bright at the
far band instead of following the fading guide. Do not create a second cube,
new diagram plane, explosion or scan beam.

Editor copy: `FOUND • CORRELATION ≈ 1`

### C — Freeze the obstruction

Decelerate to a short freeze and perform a fast camera push onto the surviving
far-shell response. Add one thin editor-drawn pointer. The pointer must target
the coral response, not the cube boundary.

Editor copy: `FREQUENCY-SHELL TAIL STAYED COHERENT`

### D — Save and refine

The PNT-13 branch turns coral and dims into the evidence ledger. A small saved
marker appears. Then one orange marker activates for the current PNT-12
frontier and camera motion resumes.

Editor copy, sequentially:

```text

COUNTEREXAMPLE SAVED
AI REFINED → PNT-12 OPEN
```

## Generator versus editor responsibility

The video model generates only continuous fluid motion, stable geometry,
camera deceleration, the close inspection and the resumed pullback. The editor
adds the expected-decay guide, exact status colors, pointer, clock, labels and
ledger markers. This prevents the model from inventing percentages, equations,
scan lines or unreadable text.

Always label the footage `CONCEPT VISUALIZATION`. The animation is a visual
analogy for frequency-shell behavior; the numerical values and logical status
come from the checked artifacts.

1. the same continuous fluid state is visible across all four stages;
2. expected decay and measured persistence are visually distinguishable;
3. the viewer can identify the exact far-shell feature that caused rejection;
4. the rejected route is saved rather than simply disappearing;
5. the active state changes from PNT-13 to PNT-12;
6. no wording implies that all 16 candidates failed because of one tail;
7. no wording implies that PNT-12 or Navier–Stokes has been proved.
