# Generation platforms

- `flow/` — default one-video route: an initial Lite clip plus three Extends.
- `higgsfield/` — targeted camera-move rescue route.
- `openart/` — full alternative image-to-video route.

Start with `../02_production/PLATFORM_COST_GUIDE.md`, choose one route, then
follow that platform's `RUNBOOK.md`. Generated clips still belong in
`../renders/`; do not store duplicate review backups here.
